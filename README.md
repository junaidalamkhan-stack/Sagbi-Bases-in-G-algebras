# ncsagbi.lib — SAGBI bases in G-algebras (Singular)

Companion code for the article

> M. A. B. Khan, J. A. Khan and M. A. Binyamin, **SAGBI Bases in G-Algebras**, *Symmetry* **11** (2019), no. 2, 221. [doi:10.3390/sym11020221](https://doi.org/10.3390/sym11020221)

The article develops SAGBI bases (canonical bases of subalgebras) in G-algebras: the SAGBI normal form (Algorithm 1), the SAGBI basis criterion via critical pairs of H-monomials (Theorem 1), and a construction algorithm (Algorithm 2). The library `ncsagbi.lib` implements these for the computer algebra system [Singular](https://www.singular.uni-kl.de), using its noncommutative subsystem Plural.

## Installation

Requires Singular (tested with 4.3.2). Copy `ncsagbi.lib` to your working directory, or to a directory on Singular's library search path (`SINGULARPATH`), and load it with `LIB "ncsagbi.lib";`. It loads `elim.lib` and `algebra.lib` itself. The procedures declare local variables inside loops, so Singular prints `// ** redefining …` notes; `option(noredefine);` suppresses them.

## Quick start (Example 6 of the article)

```
option(noredefine);
LIB "ncsagbi.lib";
ring r = 0, (e, f, h), lp;
matrix C[3][3]; C[1,2]=1; C[1,3]=1; C[2,3]=1;
matrix D[3][3]; D[1,2]=-h; D[1,3]=2e; D[2,3]=-2f;
def U = nc_algebra(C, D);     // U(sl_2): f*e = e*f - h, h*e = e*h + 2e, h*f = f*h - 2f
setring U;
ideal SB = ncsagbi(ideal(e, h^2), 10);
SB;                           // e, h2, eh+e
```

## Procedures

| Procedure | Purpose |
|---|---|
| `ncsagbi(H, max_degree)` | SAGBI basis of the subalgebra generated by the ideal `H` (Algorithm 2). New elements are normalized to leading coefficient 1 and announced as they are added; the computation stops early, returning the current set, once an added element has degree greater than `max_degree` (a guard for infinite SAGBI bases) |
| `snf(s, H)` | SAGBI normal form SNF(s \| H) of the polynomial `s` (Algorithm 1). When several H-monomials share the leading monomial, the library uses one fixed choice (Remark 2) |
| `cpairs(H, R_comm)` | T-polynomials of the critical pairs of H-monomials: those from the relations among the leading monomials (computed in the commutative ring `R_comm` returned by `elimgb`), and the commutators h_i h_j − c h_j h_i whose terms have equal leading monomials |
| `elimgb(H)` | commutative ring `R_comm` with variables x₁…xₙ, y₁…yₘ and a Gröbner basis `G` (exported) of ⟨yⱼ − LM(hⱼ)⟩ for an elimination order, used to test whether a monomial is a product of leading monomials of `H` |

The basering must be a G-algebra over ℚ (a Plural ring, defined with `nc_algebra` or e.g. `Weyl()`) with a global ordering.

## Examples (`examples/`)

| Session | Article | Content |
|---|---|---|
| `example_1_2_3_snf.sing` | Examples 1–3 | an H-monomial in A₁; SNF(g \| H) in U(sl₂) (Table 1) and in A₂ (Table 3), ordering dp |
| `example_5.sing` | Example 5 | {x², x∂, ∂²} is a SAGBI basis in A₁ (lex) |
| `example_6.sing` | Example 6 | SAGBI basis {e, h², eh + e} in U(sl₂) (lex) |
| `example_7.sing` | Example 7 | the subalgebra generated by {h, e², f², efh} in U(sl₂) (lex) |

Each session has its output stored next to it (`*_output.txt`). Examples 1–3, 5 and 6 reproduce the article; for the alternative choices of Tables 2, 4 and 5, `snf` would need a different choice of H-monomial.

**Example 7.** In U(sl₂) one has f²e² = e²f² − 4efh + 2h² + 2h, so the T-polynomial of the critical pair (p₂p₃, p₃p₂) is 4efh − 2h² − 2h = 4p₄ − 2p₁² − 2p₁, whose SAGBI normal form is 0. (The article writes eh² + h² in place of 2h² and obtains p₅ = eh² − h² − 2h.) The library adjoins instead e³f − ½e²h² − 5/2 e²h − 2e² and ef³ − ½f²h² + 3/2 f²h and then stops with a SAGBI basis of six elements; the bounded check below finds no leading monomial outside the monoid generated by their leading monomials up to degree 12.

## Tests

```
./run_tests.sh             # run every session and compare with the stored outputs
./run_tests.sh --update    # regenerate the stored outputs
```

`tests/bounded_check.sing` is an independent bounded test of the computed SAGBI bases: it forms all products of basis elements up to a degree bound in the G-algebra, computes the leading monomials of their linear span by Gaussian elimination, and checks that each is a product of leading monomials of the basis. A failure proves that a set is not a SAGBI basis, and passing is evidence, not a proof. As a negative control it detects that the input of Example 7 is not a SAGBI basis (leading monomials e³f and ef³). It uses degree 8 to 10 so that it runs in about a second; Example 7 was also checked up to degree 12 (17,420 products, about 2.5 minutes). All outputs were produced with Singular 4.3.2 (build 4330) on Ubuntu 24.04.
